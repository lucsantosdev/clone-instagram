# 📱 Clone Instagram - Estudo de Caso UI/UX

> Projeto educacional para estudar interface, experiência do usuário e evolução visual da tela de login do Instagram.

Idioma: [Português](README.md) | [English](lang/en/README.md) | [Español](lang/es/README.md)

## ✨ Visao Geral

Este projeto compara duas abordagens da mesma tela:

- 🕰️ **Versão Antiga**: referência de uma versão mais antiga
- 🚀 **Versão Nova**: proposta evoluída com melhorias de hierarquia, legibilidade e consistência

📌 O objetivo principal é praticar UI/UX com analise comparativa real.

## 🎯 Proposta do Projeto

Criar um ambiente pratico para:

- 🔍 comparar duas solucões visuais da mesma tarefa (login)
- 🧠 analisar decisões de design com base em heurísticas e boas práticas
- 📝 documentar aprendizados de UX writing, acessibilidade e fluxo
- 🛠️ transformar observações em melhorias concretas de interface

## ✅ O que foi desenvolvido

- 📰 Pagina principal com artigo interativo comparativo
- 🪟 Previews lado a lado das versões antiga e nova
- 🧩 Seções de análise UX (hierarquia, legibilidade, ações e consistência)
- 📊 Matriz comparativa de critérios de experiência
- 📚 Seção de boas práticas e materiais de estudo
- 📖 Pagina complementar sobre as 10 heurísticas de Jakob Nielsen
- 🌗 Alternancia de tema claro/escuro nas páginas principais

## 🗂️ Estrutura Atual
