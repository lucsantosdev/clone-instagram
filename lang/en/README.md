# 📱 Instagram Clone - UI/UX Case Study

> Educational project to study interface design, user experience, and the visual evolution of Instagram's login screen.

Language: [Português](../../README.md) | [English](README.md) | [Español](../es/README.md)

## ✨ Overview

This project compares two approaches to the same screen:

- 🕰️ **Old Version**: reference to an earlier version
- 🚀 **New Version**: an evolved proposal with improvements in hierarchy, readability, and consistency

📌 The main goal is to practice UI/UX through a real comparative analysis.

## 🎯 Project Proposal

Create a practical environment to:

- 🔍 compare two visual solutions for the same task (login)
- 🧠 analyze design decisions based on heuristics and best practices
- 📝 document learnings in UX writing, accessibility, and user flow
- 🛠️ turn observations into concrete interface improvements

## ✅ What Was Built

- 📰 Main page with an interactive comparative article
- 🪟 Side-by-side previews of the old and new versions
- 🧩 UX analysis sections (hierarchy, readability, actions, and consistency)
- 📊 Comparative matrix of experience criteria
- 📚 Best practices and study resources section
- 📖 Complementary page about Jakob Nielsen's 10 heuristics
- 🌗 Light/dark theme toggle on the main pages
